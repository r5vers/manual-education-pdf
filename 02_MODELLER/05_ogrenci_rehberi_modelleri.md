# Student's Guide Model 1-5 ve ICT ATM

Kaynak: SG s.7-15 (şemalar), WB s.46-47.

## Model 1-4: aynı iskeletin dört çeşidi
| Model | Bileşenler | Kontrol listesi |
|---|---|---|
| 1 | HTF + BOS + FVG | HTF likidite alımı / FVG / POI, LTF likidite alımı, BOS + displacement + FVG, FVG discount'ta (long) / premium'da (short), iyi R:R |
| 2 | HTF + BOS + **IDM** + FVG | Model 1 + BOS sonrası iç dip/tepe (inducement) süpürülür, sonra FVG'den giriş |
| 3 | HTF + BOS + FVG + **OTE** | Model 1 + FVG 0.62-0.79 aralığında |
| 4 | HTF + BOS + IDM + FVG + OTE | Model 2 + OTE |

**Her model için iki varyasyon:**
- **Failed Swing:** Sweep yok; ikinci dip birinciden yüksek kalır (HL).
- **SMT:** Diplerde korele enstrümanla uyumsuzluk.

## Model 5: Box Setup
**Short:**
1. HTF POI (tepe) yakınında orijinal konsolidasyon aralığı oluşur.
2. Agresif yükseliş POI'yi süpürür.
3. Agresif düşüş gelir.
4. Konsolidasyon tepesi yeniden test edilir → short.
5. İyi R:R aranır.

**Long:** Aynası (HTF POI dip, konsolidasyon dibinin yeniden testi).

## ICT ATM metodu [WB s.46]
1. Swing high oluşur ve buyside likidite alınır.
2. Sert ret gelir ve bir swing low kırılır (MSS).
3. FVG, Breaker veya OB'ye geri dönüşte giriş yapılır.
4. Hedef 15m/1H dip.

**Bullish versiyon:** Ayna. Her TF'de geçerli. Özünde 2022 modeliyle aynı.

## Not
Model 1 ile 2022 modeli neredeyse aynı. Fark, Model 1'in açıkça "HTF POI" şartı koyması. Kullanıcının grafiklerindeki gri HTF bölgeleri bu "HTF POI"ye karşılık geliyor gibi (bkz. 03).
